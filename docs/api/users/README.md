# Users API
Handles user account information and registration.

## Endpoints
| Method | Path                       | Summary                           | Details                                  |
|--------|----------------------------|-----------------------------------|------------------------------------------|
| `GET`  | `/api/v1/users/{username}` | Fetch a user profile by username. | [Get User](./get-user-by-username.md)    |
| `POST` | `/api/v1/users/register`   | Register a new user account.      | [Register User](./post-register-user.md) |
